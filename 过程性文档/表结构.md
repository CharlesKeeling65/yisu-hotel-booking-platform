# 数据结构（表与字段）

以下为当前 `prisma/schema.prisma` 中定义的模型与字段（本地 SQLite 开发）：

**User**
- `id: String` (主键, cuid) — 唯一标识用户，使用 `cuid()` 生成。
- `email: String` (唯一) — 用户登录邮箱，作为主要身份识别字段。
- `name: String?` — 用户显示名，可为空。
- `role: String` (默认 `user`) — 用户角色（如 `user`, `admin`），用于权限判断。
- `createdAt: DateTime` — 记录用户创建时间，用于审计和排序。
- 关系：`accounts: Account[]`, `sessions: Session[]`, `orders: Order[]` — 关联到认证账户、会话和订单记录。

**Hotel**
- `id: String` (主键, cuid) — 酒店唯一标识。
- `name_cn: String` — 酒店中文名称（必填）。
- `name_en: String?` — 酒店英文名称（可选）。
- `address: String` — 详细地址，用于展示和地图定位。
- `star_rating: Int` — 酒店星级，例如 3、4、5，整数表示。
- `opening_date: DateTime?` — 酒店开业日期（可选）。
- `facilities: String?` — 设施列表（JSON 字符串），如 `[{"name":"泳池"},...]`，可改为关系表以便搜索。
- `images: String?` — 图片列表（JSON 字符串），存储图片 URL 数组。
- `status: String` (默认 `draft`) — 酒店发布状态（如 `draft`, `published`, `archived`）。
- `merchantId: String?` — 关联的商户/合作方 ID（可选）。
- `createdAt: DateTime` — 记录创建时间。
- `updatedAt: DateTime` — 记录上次更新时间（自动更新）。
- 关系：`rooms: RoomType[]`, `orders: Order[]` — 与房型与订单的关联。

**RoomType**
- `id: String` (主键, cuid) — 房型唯一标识。
- `hotelId: String` (外键) — 所属酒店 ID，用于关联酒店。
- `name: String` — 房型名称（如 `Deluxe`, `Suite`）。
- `description: String?` — 房型描述/简介。
- `price: Float` — 单价，单位根据业务约定（例如分或元）。
- `availableCount: Int` — 可售房间数量（库存）。
- `occupancy: Int` — 建议可入住人数（如 2 表示双人）。
- `size: Int?` — 房间面积（平方米，整数，可选）。
- `amenities: String?` — 设施列表（JSON 字符串），例如 `["WiFi","早餐"]`。
- `images: String?` — 房型图片列表（JSON 字符串）。
- 关系：`hotel: Hotel`, `orders: Order[]` — 所属酒店及被预订的订单。

**Order**
- `id: String` (主键, cuid) — 订单唯一标识。
- `userId: String` (外键) — 下单用户 ID。
- `hotelId: String` (外键) — 订单对应酒店 ID。
- `roomTypeId: String` (外键) — 预订的房型 ID。
- `checkIn: DateTime` — 入住日期（含时区）。
- `checkOut: DateTime` — 退房日期（含时区）。
- `totalPrice: Float` — 订单总价（与 `RoomType.price * nights` 关系）。
- `status: String` (默认 `pending`) — 订单状态（如 `pending`, `confirmed`, `cancelled`）。
- `createdAt: DateTime` — 下单时间。
- 关系：`user: User`, `hotel: Hotel`, `roomType: RoomType` — 外键关系用于 JOIN 查询。

**Account** (NextAuth)
- `id: String` (主键, cuid) — 认证账户记录 ID。
- `userId: String` (外键) — 关联的本地用户 ID。
- `type: String` — 账户类型（如 `oauth`, `credentials`）。
- `provider: String` — 第三方提供商标识（如 `google`, `credentials`）。
- `providerAccountId: String` — 提供商在其系统中的账号 ID。
- `refresh_token: String?` — OAuth 刷新令牌（可选）。
- `access_token: String?` — OAuth 访问令牌（可选）。
- `expires_at: Int?` — 访问令牌过期时间戳（可选）。
- `token_type: String?` — 令牌类型（如 `Bearer`，可选）。
- `scope: String?` — 授权范围（可选）。
- `id_token: String?` — OpenID Connect id_token（可选）。
- `session_state: String?` — 会话状态信息（可选）。
- 关系：`user: User` — 所属用户。
- 唯一索引：`@@unique([provider, providerAccountId])` — 确保同一提供商下账号唯一。

**Session** (NextAuth)
- `id: String` (主键, cuid) — 会话记录 ID（仅在使用数据库会话时存在）。
- `sessionToken: String` (唯一) — 用于识别会话的令牌。
- `userId: String` (外键) — 会话所属用户 ID。
- `expires: DateTime` — 会话过期时间。
- 关系：`user: User` — 所属用户。

**VerificationToken** (NextAuth)
- `identifier: String` — 验证的标识符（例如 email）。
- `token: String` (唯一) — 验证令牌，用于一次性操作（如邮箱验证）。
- `expires: DateTime` — 令牌过期时间。
- 唯一索引：`@@unique([identifier, token])` — 确保同一标识符与令牌组合唯一。

---

备注：
- 目前为方便本地开发，部分多值字段（如 `images`, `amenities`, `facilities`）使用 `String` 存储 JSON 编码数组；上线/生产建议改为 JSON 类型（Postgres 的 `jsonb`）或拆分为关联表。
