# 数据结构（表与字段）

**User**

- `id: String` (主键, cuid) — 唯一标识用户，使用 `cuid()` 生成，以admin_开头的是管理端，以user_开头的是用户端。

- `email: String` (唯一) — 用户登录邮箱，作为主要身份识别字段。

- `name: String?` — 用户显示名，可为空。

- `role: String` (默认 `user`) — 用户角色（如 `user`, `admin`），用于权限判断。

- `password：String`——密码,密文

- `createdAt: DateTime` — 记录用户创建时间，用于审计和排序。

  ```sql
  CREATE TABLE `User` (
    `id` VARCHAR(50) NOT NULL COMMENT '用户唯一标识，CUID生成',
    `email` VARCHAR(255) NOT NULL COMMENT '登录邮箱，唯一',
    `name` VARCHAR(100) NULL DEFAULT NULL COMMENT '用户显示名，可选',
    `role` VARCHAR(20) NOT NULL DEFAULT 'user' COMMENT '用户角色：user/admin',
    `password` VARCHAR(255) NOT NULL COMMENT '密码密文（建议bcrypt加密）',
    `createdAt` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    PRIMARY KEY (`id`),
    UNIQUE KEY `uk_user_email` (`email`) COMMENT '邮箱唯一约束',
    KEY `idx_user_role` (`role`) COMMENT '按角色筛选索引'
  ) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='用户表';
  ```

**Hotel**

- `id: String` (主键, cuid) — 酒店唯一标识。
- `merchantId: String` — 关联的user表，确定是哪个商户创建的酒店
- `name_cn: String` — 酒店中文名称（必填）。
- `name_en: String` — 酒店英文名称（必填）。
- `province：String`—省份(必填)
- `city：String`—市(必填)
- `county：String`—区县(必填)
- `address：String`—详细地址(必填)
- `StartDate: DateTime` — 酒店开业日期（必填）
- `Label: Json` — 设施列表（JSON 字符串），只支持有停车场、有家庭房、允许宠物入住里选择(选填)
- `images: Json` — 多张图片列表，存储url列表（必填
- `status: Int `— 审核状态，0代表提交未审核，1代表审核通过已上架，2代表下架，3代表审核未通过
-  `audit_status：Int`—审核状态：0-待审核 1-审核通过 2-审核未通过'
- `online_status：Int`—上架状态：0-下架 1-上架,
- `audit_reason：String`—审核备注（未通过时填写原因）
- `auditor_id：String` — 审核人ID

- `created_time: DateTime` — 记录创建时间。
- `audit_time：DateTime`—审核时间
- `rooms：Rooms[]` -房型列表

**Room**

- `id: String` (主键, cuid) — 房型唯一标识。
- `hotelId: String` (外键) — 所属酒店 ID，用于关联酒店。
- `name: String` — 房型名称（如 `Deluxe`, `Suite`）。
- `price: Float` — 单价，单位根据业务约定（例如分或元）。
- `occupancy: Int` — 建议可入住人数（如 2 表示双人）。
- `size: Int` — 房间面积（平方米，整数，可选）。
- `images: String` — 房型图片
- `status：Int` — 房型状态 0可预订，1已售罄











```sql
CREATE TABLE `User` (
  `id` VARCHAR(64) NOT NULL COMMENT '用户唯一标识，CUID生成（admin_开头为管理端，user_开头为用户端）',
  `email` VARCHAR(255) NOT NULL COMMENT '登录邮箱，唯一',
  `name` VARCHAR(100) NULL DEFAULT NULL COMMENT '用户显示名',
  `role` VARCHAR(20) NOT NULL DEFAULT 'user' COMMENT '用户角色：user/admin',
  `password` VARCHAR(255) NOT NULL COMMENT '密码密文（bcrypt加密）',
  `createdAt` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_user_email` (`email`),
  KEY `idx_user_role` (`role`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='用户表（商户/管理员）';
```



```sql
CREATE TABLE `Hotel_Base` (
  `id` VARCHAR(64) NOT NULL COMMENT '酒店唯一标识，CUID生成',
  `merchantId` VARCHAR(64) NOT NULL COMMENT '关联User表，创建酒店的商户ID',
  `name_cn` VARCHAR(255) NOT NULL COMMENT '酒店中文名称',
  `name_en` VARCHAR(255) NOT NULL COMMENT '酒店英文名称',
  `province` VARCHAR(50) NOT NULL COMMENT '省份',
  `city` VARCHAR(50) NOT NULL COMMENT '市',
  `county` VARCHAR(50) NOT NULL COMMENT '区县',
  `address` VARCHAR(500) NOT NULL COMMENT '详细地址',
  `start_date` DATETIME NOT NULL COMMENT '开业日期',
  `created_time` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  PRIMARY KEY (`id`),
  KEY `idx_hotel_merchant` (`merchantId`),
  KEY `idx_hotel_region` (`province`, `city`, `county`),
  CONSTRAINT `fk_hotel_merchant` FOREIGN KEY (`merchantId`) REFERENCES `User` (`id`) ON UPDATE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='酒店基础信息表';
```



```sql
CREATE TABLE `Hotel_Audit` (
  `id` VARCHAR(64) NOT NULL COMMENT '审核记录ID，CUID生成',
  `hotel_id` VARCHAR(64) NOT NULL COMMENT '关联Hotel_Base表ID',
  `audit_status` INT NOT NULL DEFAULT 0 COMMENT '审核状态：0-待审核 1-审核通过 2-审核未通过',
  `online_status` INT NOT NULL DEFAULT 0 COMMENT '上架状态：0-下架 1-上架',
  `audit_reason` VARCHAR(500) NULL DEFAULT NULL COMMENT '审核未通过原因',
  `auditor_id` VARCHAR(64) NULL DEFAULT NULL COMMENT '审核人ID（关联User表）',
  `audit_time` DATETIME NULL DEFAULT NULL COMMENT '审核完成时间',
  `status` INT NOT NULL DEFAULT 0 COMMENT '兼容原状态字段：0-未审核 1-已上架 2-下架 3-未通过',
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_hotel_audit` (`hotel_id`) COMMENT '一个酒店仅一条审核记录',
  KEY `idx_audit_status` (`audit_status`),
  KEY `idx_auditor` (`auditor_id`),
  CONSTRAINT `fk_audit_hotel` FOREIGN KEY (`hotel_id`) REFERENCES `Hotel_Base` (`id`) ON DELETE CASCADE,
  CONSTRAINT `fk_audit_user` FOREIGN KEY (`auditor_id`) REFERENCES `User` (`id`) ON UPDATE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='酒店审核信息表';
```

```sql
CREATE TABLE `Hotel_Label_Rel` (

```



```sql
CREATE TABLE `Image_Storage` (

  `related_type` VARCHAR(20) NOT NULL COMMENT '关联类型：hotel（酒店）、room（房型）',
  `related_id` VARCHAR(64) NOT NULL COMMENT '关联ID（Hotel_Base或Room表ID）',

) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='图片存储表（通用）';
```



```sql
CREATE TABLE `Room` (
  `id` VARCHAR(64) NOT NULL COMMENT '房型唯一标识，CUID生成',
  `hotel_id` VARCHAR(64) NOT NULL COMMENT '关联Hotel_Base表ID',
  `name` VARCHAR(100) NOT NULL COMMENT '房型名称（如Deluxe、Suite）',
  `price` FLOAT NOT NULL COMMENT '单价（元/分，按业务约定）',
  `occupancy` INT NOT NULL COMMENT '建议可入住人数',
  `size` INT NULL DEFAULT NULL COMMENT '房间面积（平方米）',
  `status` INT NOT NULL DEFAULT 0 COMMENT '房型状态：0-可预订 1-已售罄',
  `created_time` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  PRIMARY KEY (`id`),
  KEY `idx_room_hotel` (`hotel_id`),
  KEY `idx_room_status` (`status`),
  CONSTRAINT `fk_room_hotel` FOREIGN KEY (`hotel_id`) REFERENCES `Hotel_Base` (`id`) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='酒店房型表';
```
