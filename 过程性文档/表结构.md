# 数据结构（表与字段）

以下为当前 `prisma/schema.prisma` 中定义的模型与字段（本地 SQLite 开发）：

**User**
- `id: String` (主键, cuid)
- `email: String` (唯一)
- `name: String?`
- `role: String` (默认 `user`)
- `createdAt: DateTime`
- 关系：`accounts: Account[]`, `sessions: Session[]`, `orders: Order[]`

**Hotel**
- `id: String` (主键, cuid)
- `name_cn: String`
- `name_en: String?`
- `address: String`
- `star_rating: Int`
- `opening_date: DateTime?`
- `facilities: String?` (建议 JSON 字符串或后续改为单独表)
- `images: String?` (建议 JSON 字符串列表)
- `status: String` (默认 `draft`, 如 `published`)
- `merchantId: String?`
- `createdAt: DateTime`
- `updatedAt: DateTime`
- 关系：`rooms: RoomType[]`, `orders: Order[]`

**RoomType**
- `id: String` (主键, cuid)
- `hotelId: String` (外键)
- `name: String`
- `description: String?`
- `price: Float`
- `availableCount: Int`
- `occupancy: Int`
- `size: Int?`
- `amenities: String?` (建议 JSON 字符串)
- `images: String?` (建议 JSON 字符串)
- 关系：`hotel: Hotel`, `orders: Order[]`

**Order**
- `id: String` (主键, cuid)
- `userId: String` (外键)
- `hotelId: String` (外键)
- `roomTypeId: String` (外键)
- `checkIn: DateTime`
- `checkOut: DateTime`
- `totalPrice: Float`
- `status: String` (默认 `pending`)
- `createdAt: DateTime`
- 关系：`user: User`, `hotel: Hotel`, `roomType: RoomType`

**Account** (NextAuth)
- `id: String` (主键, cuid)
- `userId: String` (外键)
- `type: String`
- `provider: String`
- `providerAccountId: String`
- `refresh_token: String?`
- `access_token: String?`
- `expires_at: Int?`
- `token_type: String?`
- `scope: String?`
- `id_token: String?`
- `session_state: String?`
- 关系：`user: User`
- 唯一索引：`@@unique([provider, providerAccountId])`

**Session** (NextAuth)
- `id: String` (主键, cuid)
- `sessionToken: String` (唯一)
- `userId: String` (外键)
- `expires: DateTime`
- 关系：`user: User`

**VerificationToken** (NextAuth)
- `identifier: String`
- `token: String` (唯一)
- `expires: DateTime`
- 唯一索引：`@@unique([identifier, token])`

---

备注：
- 目前为方便本地开发，部分多值字段（如 `images`, `amenities`, `facilities`）使用 `String` 存储 JSON 编码数组；上线/生产建议改为 JSON 类型（Postgres 的 `jsonb`）或拆分为关联表。
