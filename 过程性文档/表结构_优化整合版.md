## 1. User（用户表）

用途：统一承载管理员、商家、普通用户账号。

核心字段：
- `id`：主键，角色前缀 ID（如 `admin_xxx`、`merchant_xxx`）
- `account`：登录账号（唯一）
- `email`：登录邮箱（唯一）
- `phone`：手机号
- `name`：显示名称
- `real_name`：联系人真实姓名
- `company_name`：企业名称（商家角色）
- `role`：`admin` / `merchant` / `user`
- `password`：密文（服务端二次加密存储）
- `createdAt`：创建时间

## 2. Hotel_Base（酒店基础信息）

用途：酒店静态信息 + 搜索基础字段。

新增/关键字段：
- `star_level`：酒店星级（解决“星级漏实现”）
- `intro`：酒店简介
- `scenic_spots`：附近景点（逗号分隔）
- `latitude` / `longitude`：坐标（支持距离排序扩展）
- `featured_weight`：首页广告推广权重
- `province` / `city` / `county` / `address`：省市区县+详细地址
- `merchantId`：上传商家
- `start_date`：开业日期
- `created_time`：创建时间

## 3. Hotel_Audit（审核与上线表）

用途：审核、发布、下线全流程状态。

字段：
- `audit_status`：0待审核 1审核通过 2审核未通过
- `online_status`：0下线 1上线
- `status`：兼容状态（0未审核 1已上架 2下架 3未通过）
- `audit_reason`：审核备注/驳回原因
- `auditor_id`：审核人
- `audit_time`：审核时间
- `online_time`：上线时间

## 4. Facility_Label（标签字典）

用途：统一标签体系，支持首页快捷标签、筛选与详情展示。

预置标签：
- 免费停车
- 亲子友好
- 可带宠物
- 豪华酒店
- 商务出行
- 近地铁
- 含早餐
- 泳池健身
- 江景海景
- 免费取消

## 5. Hotel_Label_Rel（酒店-标签关联）

用途：酒店与标签多对多映射，供用户端条件查询和标签呈现。

## 6. Image_Storage（图片表）

用途：酒店头图 Banner 与房间图统一存储。

字段：
- `related_type`：`hotel` / `room`
- `related_id`：关联酒店或房型 ID
- `image_url`：图片 URL 或 base64
- `sort`：排序（酒店 Banner 左右滑动顺序）

## 7. Room（房型表）

用途：房型与价格清单（详情页按价格升序展示）。

新增/关键字段：
- `breakfast_included`：是否含早餐
- `refundable`：是否可取消
- `status`：0可预订 1已售罄
- `price`：用于用户端房型价格排序

## 8. 索引与查询优化点

- `Hotel_Base`: 地域索引 `idx_hotel_region`、星级索引 `idx_hotel_star`、广告权重索引 `idx_hotel_featured`
- `Hotel_Audit`: 审核状态索引 `idx_audit_status`、上线状态索引 `idx_online_status`
- `Room`: 价格索引 `idx_room_price`
- `Image_Storage`: 关联与排序索引（酒店轮播和房型图片加载）
