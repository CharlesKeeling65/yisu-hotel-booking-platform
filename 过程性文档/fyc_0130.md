**今日实现概述**

- **脚手架与配置**：搭建 Next.js + TypeScript + Tailwind 项目基础配置，包含 `tsconfig.json`、`next.config.js`、`tailwind.config.js` 等。
- **Prisma 与数据库（本地开发）**：使用 SQLite (`DATABASE_URL="file:./dev.db"`)，编写并调整 `prisma/schema.prisma`，`npx prisma db push` 生成 `prisma/dev.db`，并生成 Prisma Client。
- **认证**：集成 NextAuth，初期使用 Credentials Provider（用于快速开发），调整为 JWT 策略以支持 Credentials 登录，并在开发中移除 Prisma Adapter 以避免策略冲突（可在生产再启用）。
- **API 路由**：实现基本后端路由：`/api/hotels`（查询与创建）与 `/api/orders`（按 userId 查询与创建）。
- **Prisma 客户端封装**：新增 `lib/prismadb.ts`（PrismaClient 单例），避免开发环境连接过多。
- **种子数据**：添加 `prisma/seed.ts`，可一次性生成测试用户、酒店、房型、账号、会话和订单用于本地测试。
- **前端页面**：实现登录页与受保护页面：
  - `app/login/page.tsx`：客户端登录表单，使用 `next-auth/react` 的 `signIn('credentials')`。
  - `app/profile/page.tsx`：受保护个人页，使用 `useSession()`，未登录时重定向到 `/login`。
- **全局会话与头部**：新增 `app/providers.tsx`（`SessionProvider`），并在 `app/layout.tsx` 中应用；新增 `app/components/Header.tsx`，支持登录/登出与跳转。

**本地测试步骤（尽快验证功能）**

1. 安装依赖（若未安装）：

```powershell
npm install
```

2. 配置环境变量（在项目根创建 `.env`）：

```
DATABASE_URL="file:./dev.db"
NEXTAUTH_SECRET=change-me
```

3. 生成/同步 Prisma schema：

```powershell
npx prisma generate
npx prisma db push
```

4. 填充测试数据（可选但推荐）：

```powershell
npx tsx prisma/seed.ts
# 或者 npx ts-node prisma/seed.ts
```

5. 启动开发服务器：

```powershell
npm run dev
```

6. 在浏览器验证功能：

- 打开 `http://localhost:3000/login`，用 `alice@example.com` / 名称 `Alice Tester` 登录（Credentials provider）。
- 登录成功应跳转到 `http://localhost:3000/profile`，可在该页面点击 `登出` 返回首页。
- 验证 API：
  - `GET http://localhost:3000/api/hotels` 返回酒店列表
  - `GET http://localhost:3000/api/orders?userId=<userId>` 返回该用户订单

**开发注意与后续改进建议**

- 生产中建议启用 Postgres 并在 `schema.prisma` 中使用真实关系/JSON 字段（而不是 string-encoded arrays）。
- 恢复并使用 `@next-auth/prisma-adapter` 配合持久化 session（数据库策略）用于生产；目前为便于开发已使用 JWT + Credentials。 
- 添加前端表单校验、错误提示与更完整的 Auth UI（注册、密码、社交登录、邮件验证等）。
