## 📞 技术支持

### 常见问题

**Q: 我应该选择 Next.js 还是 React + Express？**  
A: 如果是新项目，强烈推荐 Next.js。优势包括：
- SSR 性能优势
- 一体化开发体验
- 部署更简单（Vercel）
- 开发效率提高 30-50%

**Q: react-date-range 如何禁用已预订的日期？**  
A: 参考第 5 章的 "5.1.3 禁用已预订的日期" 部分，使用 `disabledDates` 参数。

**Q: 如何优化超大酒店列表的性能？**  
A: 参考第 7 章的 "7.2.2 虚拟列表优化长列表"，使用 `react-window` 库。

**Q: Mapbox API 如何获取地址的坐标？**  
A: 参考第 6 章的地理编码功能 `geocodeAddress`，在 `lib/mapboxUtils.ts` 中。
